# Прежде чем писать код

**Читать `docs/checklist.md`.** Это список багов, которые в этом проекте
**уже были**. Он существует потому, что без него одни и те же вещи
проходятся по второму кругу: таймер, сбрасывающийся на переключении
вкладки, забытая кнопка «назад», двойное начисление награды — всё это
чинилось не по одному разу.

Смотреть его в двух местах: когда добавляется новый экран или режим (там
повторяется почти всё) и перед тем, как сказать «готово».

**Дополнять его обязательно.** Нашёлся баг — дописать строку в тот же
коммит, что и исправление; через день причина забудется, останется только
правка. Это относится и к решениям, которые пришлось переделать, а не
только к поломкам. Файл ценен ровно настолько, насколько он полон, и
смысл в том, чтобы каждая следующая работа начиналась не с чистого листа.

## Как здесь принято

- **Отвечать пользователю по-русски.** Комментарии и документация тоже.
- **Комментарий объясняет «почему», а не «что».** Что делает код, видно из
  кода; неочевидно, какую беду он предотвращает. Особая ценность —
  записать, что уже пробовали и почему это не сработало.
- **Живая проверка обязательна.** «По коду видно, что работает» — не
  проверка. Поднять базу, поднять сервер, сыграть. Половина найденных
  багов выглядела до проверки безупречно.
- **Замер, написанный после того, как увидены ошибки, измеряет память, а
  не качество.** Контрольные наборы пишутся заранее и не подглядываются.

## Где что лежит

| файл                   | о чём                                             |
| ---------------------- | ------------------------------------------------- |
| `docs/checklist.md`    | что проверять всегда — читать первым              |
| `docs/roadmap.md`      | план работ, не теряется между сессиями            |
| `docs/architecture.md` | устройство приложения                             |
| `docs/hot-cold.md`     | «Горячо-холодно»: правила, дуэль, словарь смыслов |
| `docs/alias.md`        | Alias за одним телефоном                          |
| `docs/deployment.md`   | развёртывание                                     |

Проверки перед коммитом:

```
npx tsc --noEmit -p apps/api/tsconfig.json
npx tsc --noEmit -p apps/web/tsconfig.json
pnpm --filter @bible-arena/api test
pnpm --filter @bible-arena/api lint && pnpm --filter @bible-arena/web lint
pnpm --filter @bible-arena/web build
```
