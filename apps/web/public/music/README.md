# Фоновая музыка

Здесь лежит `theme.mp3` — фоновая тема приложения. Файла может не быть:
тогда играет синтезированная подложка из `apps/web/src/lib/music.tsx`, и
это нормальное состояние, а не поломка.

Требования к файлу:

- **Имя ровно `theme.mp3`** — его ищет код.
- **Ровная громкость, без нарастаний.** Кульминация посреди партии
  перетягивает внимание на себя.
- **Происхождение и лицензия — в `docs/assets.md`**, в тот же коммит,
  что и файл.
- **Размер.** Чем меньше, тем лучше: файл тянется только при включённой
  музыке и кэшируется, но первый раз его качает игрок со своего
  телефона. Нынешние 6.2 МБ — потолок разумного.

## Тишина по краям

У экспорта почти всегда есть тишина в начале и в конце, и на стыке петли
она слышна паузой. Файл из-за этого не перекодируется — края обходятся
в коде константами `TRACK_HEAD_SILENCE` и `TRACK_TAIL_SILENCE`.

**При замене трека их надо сверить.** Как измерить: поднять веб
(`docs/checklist.md`), открыть приложение в браузере и выполнить в
консоли —

```js
const bytes = await (await fetch('/music/theme.mp3')).arrayBuffer();
const buffer = await new OfflineAudioContext(1, 1, 44100).decodeAudioData(bytes);
const data = buffer.getChannelData(0);
let sum = 0;
for (const v of data) sum += v * v;
const quiet = Math.sqrt(sum / data.length) * 0.1;
let head = 0;
while (Math.abs(data[head]) < quiet) head += 1;
let tail = data.length - 1;
while (Math.abs(data[tail]) < quiet) tail -= 1;
console.log({
  начало: head / buffer.sampleRate,
  конец: (data.length - 1 - tail) / buffer.sampleRate,
});
```

К измеренному хвосту прибавить примерно 0.3 с запаса: событие времени
приходит около четырёх раз в секунду, и перескок случается позже
намеченного.
