# Референсы соперников для игры в кости

В этой директории хранятся визуальные референсы персонажей-соперников:
силуэты, одежда, позы, выражения, освещение и варианты анимации.

Оптимизированные игровые ассеты не смешиваются с исходными материалами и
лежат в `apps/web/public/game/dice/opponents/`. Первый набор представляет
собой прозрачные 2.5D-портреты мужчины и женщины высотой 1024 px в WebP.

Интерьер из `female-tavern-reference.png` и `male-tavern-reference.png`
подготовлен отдельным фоновым слоем без нарисованного персонажа, переднего
стола, доски и костей. В сцене поверх него остаются настоящие 3D-объекты.
