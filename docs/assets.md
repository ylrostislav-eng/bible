# Файлы со стороны: происхождение и лицензия

Здесь записывается всё, что пришло в репозиторий готовым — звук,
музыка, картинки. Правило одно: **строка появляется в том же коммите,
что и файл.** Через месяц происхождение забудется, а вопрос останется, и
отвечать на него придётся уже под давлением.

Синтезированных звуков это не касается: щелчки, «верно», исход партии и
запасная подложка собираются осциллятором в
`apps/web/src/lib/sound.tsx` и `apps/web/src/lib/music.tsx` — файлов у
них нет, лицензировать нечего.

## `apps/web/public/music/theme.mp3`

| что            | значение                                               |
| -------------- | ------------------------------------------------------ |
| что это        | фоновая тема приложения                                |
| происхождение  | сгенерирована владельцем проекта нейросетевым сервисом |
| дата           | 2026-09-05                                             |
| лицензия       | **уточняется** — см. ниже                              |
| длительность   | 6 мин 47 с, стерео, 44.1 кГц                           |
| размер         | 6.2 МБ                                                 |
| правки в файле | нет; тишина по краям обходится в коде                  |

**Что осталось выяснить.** Права на коммерческое использование у
генеративных сервисов обычно зависят от тарифа: на бесплатном
результат чаще всего разрешён только для личных целей. Приложение
публичное, поэтому тариф на момент генерации стоит проверить и вписать
сюда — вместе со ссылкой на условия. Пока это не сделано, строка
остаётся с пометкой «уточняется», а не с придуманной лицензией.

**Измеренное.** Пик 0.83, RMS 0.146 — трек сведён нормально, без
перегруза. Тишина по краям: 0.51 с в начале, 0.32 с в конце. В файле она
не тронута: перекодирование mp3 — это потеря качества ещё раз и версия в
репозитории, отличная от присланной. Вместо этого проигрывание
перескакивает через края, см. `TRACK_HEAD_SILENCE` и
`TRACK_TAIL_SILENCE`.
